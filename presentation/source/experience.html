// Product decisions

Two ways to run it

A standard-library Python CLI for terminal use, plus a responsive static web app.

Built for repeated turns

Quick prompts make supported intents discoverable; new chat restarts the conversation after a clean exit.

Client-side by design

The browser app can run on static hosting without a chatbot backend or server-side conversation store.
